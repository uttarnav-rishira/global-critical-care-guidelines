# Open-access full-text source documents

This folder contains complete guideline PDFs that the project has verified may be redistributed in this public repository under the stated licence or explicit permission.

## Rules

1. **No automatic mirroring.** Publicly readable does not mean redistributable. A free publisher page, PubMed Central copy, institutional repository copy, or author manuscript is not sufficient evidence by itself.
2. **Check the exact rights.** Confirm that the licence applies to this specific document/version and permits redistribution in a public repository. Record any attribution, non-commercial, no-derivatives, share-alike, or other conditions.
3. **No restricted files.** Do not upload paywalled, subscription-only, access-restricted, copyright-restricted, or licence-unclear PDFs. Keep their official links and access status in the screening register instead.
4. **Keep the catalogue lightweight.** The main index in `data/guidelines.csv` should contain bibliographic metadata and links, not embedded full text. This folder is a separate, permission-controlled document collection.
5. **Manifest required.** Every PDF must have a completed row in `manifest.csv`. The manifest records the guideline ID, DOI, issuing organisation, year, version, original URL, access date, licence, and attribution/conditions.
6. **Verify provenance.** Check that the PDF is complete and matches the cited edition. Preserve the original source URL and a durable record of licence/permission evidence.
7. **No empty claims.** Do not list a PDF in the manifest until the file is committed and its redistribution rights are verified.

## Folder organisation

Create subfolders by issuing organisation only when useful. Use stable filenames such as:

`GCCG-000123_2025_issuing-body_short-title.pdf`

## Important distinction

This folder is a research archive, not a clinical decision-support service. Inclusion does not imply that a guideline is current, endorsed by this project, or suitable for an individual patient.
